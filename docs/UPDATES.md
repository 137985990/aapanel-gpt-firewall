# 更新管理

## 从哪个版本开始支持

社区更新入口从 v0.1.1 开始提供。当前目标版本为 v0.1.2，v0.1.1 用户可直接使用现有入口确认升级。旧 v0.1 无此功能，须按 [升级教程](UPGRADE.md) 手动上传 v0.1.2 升级包，不必先装 v0.1.1，也不能靠没有安装的更新器自动升级自身。内部插件名仍为 `free_waf`，不另装第二个插件。

## v0.1.2 的包兼容约定

v0.1.2 运行 ZIP **严格保持 v0.1.1 的 21 个受管文件集合不变**，旧更新器不需要放宽文件白名单就能校验新包。新增端点策略与安全边界测试、Lua 审计脚本、接口／统计画廊图片只进入公开源码快照；总览截图仍在原受管集合中。不要把源码包当安装包，也不要为显示画廊或补依赖绕过校验。

升级不会自动添加或启用站点 `endpoint_limits`，不会改原防护阈值。新建接口规则默认停用、动作为观察；需要时由管理员选择站点并保存启用。接口采样事件位于既有 WAF 日志目录，受日志开关、写入状态和读取限额影响，不纳入受管代码覆盖或代码回退。

本版同时移除旧 `security_verification` 算术／JavaScript 挑战，改为通用 429 JSON 与 `Retry-After`，不反射 URI、不建立 IP 验证绕过；旧 CC 按站点和不含查询串的规范化路径计数。管理员应在测试环境验证正常客户端重试，不把“配置未变”理解为所有运行行为完全不变。

## 自动检查，不自动安装

打开插件后延迟检查固定社区 GitHub 仓库，检查结果缓存 6 小时，不占用首屏加载；可在“更新管理”手动刷新。关闭插件后不承诺按时定期检查，也不会自动下载或安装版本。

手动强制检查仍有最短 60 秒间隔，避免连续点击触发 GitHub 限流。在线升级包必须符合当前更新器的固定受管文件清单；未来若需要新增文件或依赖，会另行提供迁移说明，不能通过放开压缩包白名单强行安装。

仅识别已发布的合法数字版本，草稿不展示；预发布会明确提示。版本不是按字符串排序，v0.1 等价于 0.1.0；不会降级或重新安装相同版本。服务器无法连接 GitHub 或被限流时保留明确提示，现有防护继续运行，可改用离线升级。

正常分块响应可以读取。真实联网在独立短进程中进行，单次请求超过 10 秒时结束该进程并回收结果，覆盖 DNS、TLS、响应头和正文阶段，避免慢连接长期占用检查请求或更新锁；超时不会触发安装。进程创建、系统资源或强制结束本身仍受操作系统状态影响。

## 一键更新流程

1. 查看目标版本和更新说明，先保留独立备份与管理通道。
2. 点击一键更新并确认。浏览器仅提交目标版本号，不提交自定义下载地址或安装命令。
3. 后台重新核对发布记录，下载固定来源附件，验证 SHA256SUMS 和存在时的 GitHub 附件摘要，检查 ZIP 路径、大小、重复项、链接、受管文件白名单与版本。
4. 先备份受管插件代码和运行时代码，再逐文件原子替换，调用包内离线安装器；保留规则、站点配置（含已有 `endpoint_limits`）、黑白名单、接口事件及其他日志和 `data`。逐文件原子替换不等于整个包具备事务原子性。
5. 查看后台任务结果。成功后关闭并重开插件，核对宝塔 Nginx 配置、插件与安装状态版本 `0.1.2` 和正常业务；不要仅因界面显示完成就认定所有站点验收通过。可选接口策略的配置与验证步骤见 [README](../README.md)。

检查和状态查询都不是安装授权。只有明确确认安装才启动独立后台任务，关闭浏览器不会取消已确认任务；不要重复点击或同时用面板上传其他更新。

## 失败与回退

更新记录与代码备份保存在插件私有 data/updates 范围。失败时执行器尝试恢复本次受管文件和运行时代码，分别报告安装失败与回退状态；回退失败不能显示为更新成功。不要公开整个目录，可能包含管理路径和旧代码。

检测到同期人工修改时，不会强行覆盖这些变更；恢复冲突会显示失败并阻止再次启动更新，需要管理员先核对文件与备份。请勿删除任务记录来绕过未完成恢复的保护。

自动回退不恢复全部 Nginx 内存状态、应用数据或无关同期变更，也不能代替独立备份。进程被系统终止、断电、磁盘损坏等情况下需要核对任务记录并人工恢复。仅使用宝塔 Nginx 检查和平滑重载，不重启面板或调用系统 Nginx；重载信号成功仍需核实业务。

接口临时计数与限域封禁不等于持久黑名单，运行时生命周期会影响状态；不能靠恢复旧代码来重建全部状态。站点配置、采样事件、访问日志属于保留数据，不为了代码回退自动覆盖成旧副本。若确需恢复数据，应另行确认时间范围与后果。

## 信任边界

固定仓库为 137985990/aapanel-gpt-firewall，网络使用验证证书的 HTTPS，不接受任意下载镜像。校验值与附件均来自 GitHub，能发现传输损坏或摘要不一致，但不能在仓库账户或发布渠道被攻破时提供独立签名保证。升级包含可执行代码，管理员应核对来源与更新说明。

此功能不接管 aaPanel 商店的上游升级。请勿同时使用旧商店自动升级覆盖社区代码，也不要运行旧卸载器来重装；兼容与手工恢复步骤见 UPGRADE.md。
